# C1-04: sender integration and current acceptance evidence

## Implementation

The sender CLI now supports explicit `--send --port COMx` with one of `--text`, `--audio`, or `--record`. Default interactive recording and all commands without `--send` remain text-only. `--list-ports` enumerates devices without opening them; `--check-serial --port COMx` checks identity/readiness without sending text. Invalid port names and incompatible option combinations are rejected before recording. Normalized text is validated before opening a send connection, and the exact outgoing bytes are displayed separately from the original transcript. No private compression or truncation is used.

`serial_connection.py` owns a bounded connection lifecycle around the existing shared-helper serial adapter: read boot hello/ready, send at most one fallback HELLO after two seconds if hello has not arrived, enforce the shared five-second discovery deadline, send only when ready, and poll through acceptance, local sent, and the next ready. Ports close on success, timeout, failure or interruption. No automatic reconnect/resend occurs. Each CLI send invocation opens one connection after transcription/validation, completes or reports uncertainty, then closes. Repeated live sends are separate explicit invocations; interactive mode does not send. A local sent event is never treated as remote receipt.

Changed implementation files in the existing `841122f` C1-04 commit: `cli.py`, `serial_adapter.py`; new `serial_connection.py`, `tests/test_sender_integration.py`. Existing dependencies, model artifacts and shared protocol/consumer pins were not changed. This handoff, tracker and current usage documentation complete the interrupted documentation work. Earlier C1-01/C1-02/C1-03 handoffs are historical and remain unchanged.

## Commands after Tx firmware is uploaded

Run from the usual repository root, choosing the current enumerated port (COM8 may change):

```powershell
sender/.venv/Scripts/python.exe sender/cli.py --list-ports
sender/.venv/Scripts/python.exe sender/cli.py --check-serial --port COM8
sender/.venv/Scripts/python.exe sender/cli.py --send --port COM8 --text "Spirit, what is your name?"
sender/.venv/Scripts/python.exe sender/cli.py --send --port COM8 --record --seconds 5
```

The last command records for a bounded five seconds and then transcribes/sends; Ctrl+C during recording discards the recording. Keep utterances within the shared 48-byte ASCII limit. Edit an overlong/non-ASCII transcript using `--text` rather than silently changing it. If a send becomes uncertain, inspect the cause and explicitly reconnect; a new rendition may duplicate a remotely received message. No automatic retry is attempted.
