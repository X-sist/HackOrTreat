## Behavior
- Interactive Python CLI: Enter starts capture, Enter stops; 10-second default, configurable 0.25–30 seconds; Ctrl+C cancels/discards a recording; t=manual text, d=devices, q=quit.
- Explicit --record timed capture, --list-devices enumeration, --text without model/mic, --audio for existing local audio, --device input selection. Redirected stdin requires an explicit mode.
- Captures mono at the selected device's native sample rate into a bounded preallocated buffer, then builds an in-memory 16-bit PCM WAV. Whisper's existing decoder resamples it to the model rate. Audio is not saved by the CLI.
- Clear missing-local-model/file, no-device, open/permissions, stall, overflow and too-short errors. Blank transcription is not presented as recognized speech. Recognized text is displayed unchanged; transport cleanup/bounds remain C1-03.
- Local CPU INT8 Whisper model is loaded lazily and reused between utterances. Model artifacts are verified before first use; local_files_only/HF offline flags/Python socket and DNS denial cover model construction and lazy segment iteration. No cloud fallback.
- Added sounddevice0.5.6 plus cffi2.1.1 and pycparser3.12. Existing 25 package versions unchanged, including the required PyAV16.0.1 compatibility pin. All 28 wheels are officially hash-verified and locked; install was sender-local from cached wheels.
