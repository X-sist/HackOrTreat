# T03: Receiver Stream Parser, Shared Contract Validator & Plain-Text Output

## Implementation

CS Major 2 (@Xsist) has implemented deliverable **T03** in the `receiver/` component:
1. **Bounded Serial Stream Parser (`receiver/src/stream_parser.mjs`)**:
   - Implements the host-board NDJSON event parser following `docs/PROTOCOL.md` v1 specifications (115200 8N1, LF-delimited, optional CR accepted, empty lines ignored).
   - Enforces strict buffer bounds: lines exceeding `MAX_EVENT_LINE_BYTES` (256 bytes) trigger a `LINE_TOO_LONG` error and discard bytes until the next LF, preventing execution of any truncated prefix.
   - Validates each parsed object against `shared/js/contract.mjs` (`validateEvent(parsed, 'rx')`).
   - Decodes `payload_hex` into clean printable ASCII text (32–126).
   - Dispatches callbacks for `message`, `disturbance`, `duplicate`, `hello`, `protocol_error`, and `error`.
2. **Plain-Text Receiver CLI (`receiver/src/cli.mjs`)**:
   - Supports `--stdin` for streaming serial piped input.
   - Supports `--replay <file>` for NDJSON record replay.
   - Supports `--fixtures` to replay all valid shared rx fixtures.
   - Supports `--simulate` for standard demo scenario verification.
3. **Ouija Spirit Plane UI & Server (`receiver/src/server.mjs`, `receiver/public/`)**:
   - Built on Node.js native `http` with Server-Sent Events (`/events`) requiring zero external npm dependencies.
   - Serves the weathered mahogany wood and dark slate Ouija tablet interface.
   - Displays real-time message transcription, animates the digital planchette, and renders screen glitch / alert banners on `disturbance` (e.g. `CHECKSUM_FAILED: CRC_MISMATCH` or `INCOMPLETE_PACKET: INDEX_GAP`).
4. **Verification Hook (`receiver/verify.py`)**:
   - Component verification hook runnable via `python receiver/verify.py --ci`.
   - Runs the test suite `node receiver/tests/test_stream_parser.mjs`.

## Actual Evidence

- **28 assertions passed** across 9 test groups in `test_stream_parser.mjs`:
  - Single message parsing and ASCII hex decoding.
  - Multi-chunk split read reassembly.
  - Multiple events per chunk with `\r\n` and blank lines.
  - Disturbance events (`CHECKSUM_FAILED`, `INCOMPLETE_PACKET`).
  - Duplicates and protocol error handling.
  - Bounded read overflow discarding (>256B lines).
  - Malformed JSON rejection.
  - Replay of all `rx` shared fixtures from `shared/fixtures/events.json` (all valid accepted, all invalid rejected).
- Zero external npm packages required (`dependencies: {}` in `package.json`).

## Commands to Run

From repository root:

```powershell
# 1. Run receiver tests
node receiver/tests/test_stream_parser.mjs

# 2. Run component verification hook
python receiver/verify.py --ci

# 3. Replay shared event fixtures in CLI
node receiver/src/cli.mjs --fixtures

# 4. Run interactive demo simulation in CLI
node receiver/src/cli.mjs --simulate

# 5. Start the Ouija Spirit Plane Web UI
node receiver/src/server.mjs
# Then open http://localhost:3000 in your browser
```
